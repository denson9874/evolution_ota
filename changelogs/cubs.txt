Evolution X 12.3 (Android 17) for the Pixel 11 (cubs), build 20261022
Security patch: 2026-10-01 (system), 2026-10-05 (vendor). Stock Pixel firmware CD1A.261005.003.

Notes:
==============================
- The update includes the stock Pixel firmware CD1A.261005.003 (bootloader and radio).
- Rooted? Before rebooting, install Magisk (or KernelSU) to the inactive slot, or root is gone after the update.
- Kernel: Espada v3 (Linux 6.12.92) by Kevtrejo37 (CASS scheduler, Simple LMK, GrapheneOS zram fix; source: https://github.com/atrejokm301/espada-kernel).
- First installs need a computer: see https://xdaforums.com/t/4804723/

Device changes:
==============================
- drop the bring-up TARGET_DISABLE_EPPE
- carry the NetworkPolicy fixes for apps cut off from the network
- display and UI parity with stock
- NFC parity: stock libnfc-nci.conf, NFC on by default, FeliCa
- add a tethering overlay so USB tethering uses NCM
- telephony parity: CarrierSetup, WfcActivation, APN source, IMS location
- ship the mainline supplicant config overlays
- ship EuiccGoogle, the eSIM LPA, and the eUICC SE overlay

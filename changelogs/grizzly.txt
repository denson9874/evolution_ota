Evolution X 12.3 (Android 17) for the Pixel 11 Pro (grizzly), build 20261016
Security patch: 2026-10-01 (system), 2026-10-05 (vendor). Stock Pixel firmware CD1A.261005.003.

Notes:
==============================
- Untested: this build has never been booted on a Pixel 11 Pro. If it doesn't boot, the phone goes back to the build you had.
- The update includes the stock Pixel firmware CD1A.261005.003 (bootloader and radio).
- Rooted? Before rebooting, install Magisk (or KernelSU) to the inactive slot, or root is gone after the update.
- Kernel: Espada v3 (Linux 6.12.92) by Kevtrejo37 (CASS scheduler, Simple LMK, GrapheneOS zram fix; source: https://github.com/atrejokm301/espada-kernel).
- First installs need a computer: see https://xdaforums.com/t/4804712/

Device changes:
==============================
- allow hal_power_server sysfs_batteryinfo access for priority charging
- manage vendor_kernel_boot in grizzly-images to avoid Soong denylist
- integrate Espada kernel with stock GKI fallback
- get over-the-air updates from this tree's own OTA repo
- ship Google's charging screensaver
- apply-patches: don't misdetect applied patches near the top of the log
- fix the charging screensaver's battery level and digits
- hold AOD at the dimmed brightness until it has animated in
- let RisingOS builds through the artifact-path check
- README: list the frameworks/base patches
